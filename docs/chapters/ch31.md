# §15 — Chapter 31: Preoperative Evaluation

> Chapter ledger entry, relocated from `goldenversion.md`. Historical record — read only if
> you need this chapter's detailed rationale.

**Content classification.** Ch31 (Wijeysundera & Finlayson) is almost entirely **Bucket B** (clinical judgment / decision-support / risk-scoring) with a phase-of-care home overwhelmingly in **PreOp** — it is the textbook's own dedicated preoperative-evaluation chapter, not a physiology/PK-PD chapter. No Bucket C (procedural/technique) content is present. All additions below live in `PreOpEMR.jsx`, which was already the simulator's PreOp surface (Ch30's RCRI calculator lives there too), so this chapter extends that existing surface rather than creating a new one.

**Source-extraction note:** several of this chapter's tables (Table 31.2 Duke Activity Status Index item list, Tables 31.11/31.12 DOAC discontinuation interval matrices) are scanned table images in the source PDF that did not OCR as literal text — only their captions and surrounding narrative did. Where this is the case, the gap is filled with the published, well-established version of the same instrument/guidance (disclosed below per item), consistent with the "best-reasoned estimate, disclosed" standard now in effect for Bucket B content — never presented as directly transcribed from this chapter's own tables.

#### 15.1 Objective Functional Capacity: the Duke Activity Status Index (`calculateDasiMets`, `DASI_ITEMS`, `PreOpEMR.jsx`)

The simulator's existing METs assessment (from the Ch30-era risk quiz) was a binary "adequate (≥4 METs) / poor (<4 METs)" judgment call with no underlying calculation. Ch31 (p.5-6) explicitly critiques subjective METs assessment — anesthesiologists' unaided judgment has only **19% sensitivity** for detecting a patient's inability to reach 4 METs on formal exercise testing — and recommends the **Duke Activity Status Index (DASI)**, a 12-item self-administered questionnaire (Hlatky et al., *Am J Cardiol* 1989), with the conversion formula given explicitly in the chapter text:

$$\text{Estimated METs} = \frac{(0.43 \times \text{DASI score}) + 9.6}{3.5}$$

*   **`DASI_ITEMS`**: the 12 published DASI items and point weights (summing to the instrument's known maximum of 58.2) — sourced from the original Hlatky 1989 instrument since Ch31's own Table 31.2 did not OCR with item-level text, disclosed per the note above.
*   **`calculateDasiMets(dasiAnswers)`**: sums weighted points for checked items, applies the chapter's own formula, and classifies the result against the same ≥4/<4 METs threshold the chapter cites for the AHA/ACC stress-testing decision.
*   Surfaced in `PreOpEMR.jsx`'s Risk Assessment tab as a **supplementary tool**, separate from the graded RCRI/METs quiz (so it doesn't change existing grading behavior) — a real interactive calculator the user can apply to any patient, with a live DASI-score → METs → recommendation readout.

#### 15.2 BMI Classification (Table 31.3) and the Airway Examination (Box 31.1)

*   **`classifyBmi(bmi)`**: replaces the chart tab's prior ad hoc BMI labeling (`bmi > 35 ? 'Obese Class II' : ...`) with the actual CDC six-tier scheme Ch31 cites (Table 31.3): Underweight (<18.5) / Normal (18.5-24.9) / Overweight (25-29.9) / Obese I (30-34.9) / Obese II (35-39.9) / Obese III (≥40).
*   **`assessAirwayExamBox311(patient)`**: implements the chapter's explicit "concerning" thresholds from Box 31.1 — interincisor/intergum distance **< 3 cm**, thyromental distance **< 6 cm**, Mallampati **≥ class 3**. The simulator does not track literal centimeter measurements for these exam components, so interincisor/thyromental distance are derived from the existing Mallampati-class and neck-mobility flags via a disclosed, deterministic mapping (not a chapter-sourced numeric table) — flagged inline in the function's own comment. Surfaced as a new "Airway Examination (Box 31.1)" card in the Chart tab.

#### 15.3 Perioperative Anticoagulant & Antiplatelet Management (`calculateAnticoagulationPlan`, `calculateCha2ds2VascScore`)

This is the chapter's most directly actionable content and replaces a previously hardcoded, clinically arbitrary line in `PreOpEMR.jsx`'s Medications & Allergies card (`"Apixaban (Eliquis) 5mg BID (held 48 hours pre-op)"` — a fixed 48h hold regardless of renal function or bleeding risk) with a real, exported, unit-tested calculation:

*   **Aspirin** (if `patient.cad`): chapter-text-sourced rule — continue perioperatively in patients with high-grade IHD (continuation is not a contraindication to neuraxial blocks; withdrawal carries a theoretical rebound-hypercoagulable risk not supported by trial data for the general case modeled here).
*   **Warfarin**: hold **5 days** before surgery (directly stated), recheck INR within 24h, give low-dose oral vitamin K for any INR > 1.5 — all directly sourced from the chapter text.
*   **DOACs**: hold interval tiered by eGFR (≥50 → 48h, 30-49 → 72h, 15-29 → 96h, <15 → insufficient data, individualize with hematology). The eGFR-tiering concept and the "bridging generally not needed for DOACs" rule are directly chapter-sourced; the specific hour values are a disclosed best-reasoned estimate following standard ACC/ASRA practice, since the chapter's own Tables 31.11/31.12 did not OCR as text (see source-extraction note above).
*   **`calculateCha2ds2VascScore(patient)`**: CHA2DS2-VASc score (CHF=1, HTN=1, age≥75=2/age 65-74=1, diabetes=1, prior stroke/TIA=2, vascular disease=1, female sex=1) drives the chapter's own bridging-therapy decision rule: score ≤4 with no recent stroke/TIA → omit bridging; score ≥7 or recent (≤3mo) stroke/TIA → consider bridging; intermediate → individualize. Directly sourced from the chapter's BRIDGE-trial discussion.
*   **Neuraxial-specific timing**: when a neuraxial technique is planned (`anesthesiaPlan.types.neuraxial`), an additional entry surfaces the chapter's directly-stated ASRA minimums — prophylactic LMWH ≥12h, therapeutic/bridging LMWH ≥24h, IV unfractionated heparin ≥6h before block.

**New clinical advisory** (`getAnesthesiaAdvisories()`): planning a neuraxial technique on a documented atrial-fibrillation patient now surfaces a `warning`-severity advisory citing the specific computed DOAC hold action, rather than the prior advisory set (which only covered septic/trauma neuraxial contraindications).

#### 15.4 Quality-of-Care Hook: Unconfirmed Anticoagulant Hold Before Neuraxial Instrumentation

Consistent with the `QualityEvent` infrastructure (see the Ch9-30 retroactive sweep ledger entry), locking an anesthesia plan (`handleProceed()`) that combines a neuraxial technique with a documented AFib/anticoagulated patient now emits a `major`-severity, `ChecklistAdherence`-category, `PreOp`-phase `QualityEvent` (`chapterSource: 'Ch31: Preoperative Evaluation — Atrial Fibrillation / Anticoagulant Management'`) — the simulator does not block the plan (consistent with the "score, don't always hard-block" pattern for clinically real but non-catastrophic-in-the-moment choices), but the structured record exists for a future debrief to attribute a spinal/epidural hematoma risk to the actual decision that created it. `logQualityEvent` was threaded as a new prop through `App.jsx` → `PreOpEMR.jsx` (both render call sites) to make this possible.

#### 15.5 What Was Not Integrated This Session

Ch31 is a 77-page, extremely broad chapter covering atrial fibrillation/CIEDs/arrhythmias, cerebrovascular disease, neurologic disease (seizure disorders, Parkinson disease, multiple sclerosis), pheochromocytoma, and detailed CKD/AKI pathophysiology, among others. Consistent with how prior chapter sessions have scoped large chapters (representative, high-value integration rather than exhaustive line-by-line coverage), this session focused on the content with the clearest path to a real, scorable, currently-missing simulator feature: functional capacity (DASI), BMI/airway exam thresholds, and perioperative anticoagulant management. **Not integrated this session** (left as narrative source material for a future pass, not fabricated into the simulator without source grounding): CIED (pacemaker/ICD) perioperative management, Brugada/Long-QT preoperative workup, the chapter's detailed neurologic-disease-specific preoperative guidance (seizure disorders, Parkinson disease, multiple sclerosis), pheochromocytoma workup, and P2Y12-inhibitor-specific (clopidogrel/ticagrelor/prasugrel) discontinuation intervals — none of these map to an existing patient flag the simulator currently models, so adding them now would have required inventing patient state rather than wiring real chapter content to real simulator data.
